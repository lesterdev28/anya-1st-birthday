# Higgsfield prompt pack — Anya's first birthday invitation

Copy one block at a time into higgsfield.ai. Generate in the order below.

**The one rule that matters: generate Asset 1 first and don't move on until you
love it.** Everything else is built from it, either by pasting it in as a
reference image or by matching it. If you generate the videos independently of
the hero image you will get a different castle, and the site will look like two
different worlds stitched together.

**Never let the image generate text.** No name, no date, no "You're Invited".
All wording is rendered by the website so it stays sharp and correctable.

## The style block

This paragraph is what keeps every asset in the same world. Paste it at the end
of every prompt below, unchanged, every time.

```
STYLE: premium cinematic fairy-tale storybook illustration. Palette strictly
pastel lavender, blush pink, powder blue, warm ivory, champagne gold and soft
peach. Dreamy volumetric lighting with a gentle golden glow, soft depth of
field, delicate whimsical storybook detail. Completely original fantasy world.
No text, letters, numbers or watermarks anywhere in the image. No recognizable
franchise castles, no existing cartoon or film characters, no princess
likenesses. Not cartoonish, not clip-art, not harsh, not saturated.
```

## Order and budget

You have 110 credits and video costs far more than images, so spend in this
order and stop wherever you run low. I can't see Higgsfield's per-generation
pricing, so watch the counter as you go.

1. **Asset 1, hero vertical.** Non-negotiable, everything keys off it. Expect
   to run it a few times to get the open sky right.
2. **Asset 3, opening cinematic.** The single biggest "wow" on the site.
3. **Asset 5, storybook cover.** Needed for the opening animation.
4. **Asset 2, hero wide.** Only matters on desktop; the vertical can be used
   for both at a push.
5. **Asset 4, castle reveal.** Lovely, but if credits are tight I can cross-fade
   from the opening video into the hero and you'd barely notice.
6. **Asset 6**, then the decorative set, then the month art.

If you can only afford two things, make them Asset 1 and Asset 3.
